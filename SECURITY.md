# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

Report vulnerabilities privately via [GitHub Security Advisories](https://github.com/wielorzeczownik/pepito-client/security/advisories/new).

Include as much detail as possible:

- Description of the vulnerability
- Which binding is affected (Rust crate, npm package, Composer package) and, for npm and Composer, which backend (the default plain TS / PHP one, or wasm / FFI)
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

You will receive a response within **7 days**. If the issue is confirmed, a fix will be released as soon as possible and you will be credited in the release notes (unless you prefer to remain anonymous).
