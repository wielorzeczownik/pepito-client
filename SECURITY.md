# Security

Thanks for taking the time to look. Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/wielorzeczownik/pepito-client/security/advisories/new) instead of a public issue, so there's a chance to fix them first. You'll be credited in the release notes unless you'd rather not be. Only the latest release gets fixes.

It helps to mention which package is affected (Rust crate, npm or Composer) and, for npm and Composer, which backend: the default plain TS or PHP one, or wasm or FFI.
